# Lab 2 - Personal Portfolio Page

A simple personal portfolio page built with **HTML** and **CSS** for the CSE343 Web Development course.

## Features

- Header with name, title and navigation links (About, Projects, Contact)
- **About Me** section
- **Projects** section with three project cards
- **Contact Me** form with name, email and message fields
- Footer with copyright text

## Files

| File | Description |
|---|---|
| `lab2.html` | The page structure (HTML) |
| `lab2.css` | The page styling (CSS), linked from the HTML file |

## How to Run

1. Download or clone this repository.
2. Keep both files in the same folder.
3. Open `lab2.html` in any web browser.

- HTML
